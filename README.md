# المصحف الشريف

تطبيق ويب للمصحف كاملًا (١١٤ سورة بالرسم العثماني) مع تلاوات كبار القراء:
ياسر الدوسري، ماهر المعيقلي، مشاري العفاسي، محمد صديق المنشاوي، عبد الباسط، الحصري، السديس، الشريم.

- بحث عن السورة بالاسم أو الرقم، والانتقال لأي آية
- مشغّل صوت: تشغيل/إيقاف، السورة التالية والسابقة، شريط تقدّم، تشغيل تلقائي
- وضع ليلي وتكبير الخط، ويفتكر آخر سورة والقارئ
- يتثبّت على الموبايل والكمبيوتر كتطبيق (PWA)، والسور اللي اتفتحت قبل كده تشتغل من غير نت

## المصادر
- النص: [api.alquran.cloud](https://alquran.cloud/api)
- الصوت: [mp3quran.net](https://mp3quran.net)

## التشغيل محليًا
```
python -m http.server 8765
```
وبعدين افتح `http://localhost:8765`.
